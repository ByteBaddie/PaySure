# PaySure

> **Confidence before every payment.**

PaySure is a transaction safety assistant designed to help users assess digital payment risks before completing a transfer.

## 🚀 Overview

PaySure adds a safety layer before payment confirmation by assessing transaction details and presenting users with understandable risk indicators.

The prototype combines rule-based risk scoring, scam-pattern detection, explainable alerts, recipient verification, and a cooling-off step for high-risk transactions.

## ✨ Key Features

- Composite transaction risk scoring
- Explainable risk alerts
- Scam-pattern detection
- Recipient verification
- Safety checklist before payment
- Cooling-off period for high-risk transactions
- Transaction history

## 🔄 User Flow

**Enter → Assess → Pause → Confirm**
